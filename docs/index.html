Everything a creator needs. Nothing they don't.

Built for real creator setups: OBS running, Discord open, one mic shared between them.

🎥

OBS sync

Record, pause and stop together. Scene changes become markers. Multi-track OBS recordings import as separate tracks.

🪄

Studio Sound

One click analyses your voice and builds a clean chain: denoise, EQ, de-ess, compress, -16 LUFS. Fully editable.

⏪

Never miss a take

A rolling buffer keeps the last 60 seconds. Said something great before hitting record? Save it.

🎛

Live effects

Move a slider and hear it instantly. Exports use the same engine, so the file matches what you heard.

🛟

Crash-safe recording

Takes are written continuously and repaired after a crash or power cut. Unplugged mic? Your take is kept.

📦

All open formats

WAV, FLAC, MP3, Ogg, Opus, AAC, AIFF and audio from MP4/MKV in. WAV, FLAC, MP3, Opus, Ogg and more out, with tags.

🤝

Shared mic, always

Never takes exclusive control of your microphone. OBS, Discord and your browser keep working alongside.

🩺

Live mic check

Warnings for clipping, too quiet, a dead channel or mains hum, before they ruin a recording.

✂️

Non-destructive editing

Cut, copy, paste with full undo. Originals never change. Projects autosave and recover after a crash.

🛡

Safety track new in 0.9

Every recording is also written as a −12 dB copy. Clipped a take? Boost the safety file and rescue it.

🎙

Voice-triggered recording new in 0.9

Set a level threshold: recording starts when you speak and stops shortly after you stop. Ideal for long streams.

🧹

Silence auto-trim new in 0.9

Find the pauses on a track in one click, see how many there are, and trim them all in one undoable step.

🎚

Per-clip gain & fades new in 0.9

Every clip gets its own gain and fades. Duck music under a voiceover and smooth punch-ins.

📤

Batch export new in 0.9

Export every track as a 24-bit WAV in one pass, each brought to −14, −16 or −23 LUFS.

▶️

Mixdown playback new in 0.9

Hear the whole project: every track played together with its effects.

📝

Whisper transcription new in 0.9

Transcribe takes locally with any whisper.cpp model. Speech-to-text on your machine, no cloud.

Made to sit next to OBS

StreamWave talks to OBS 28+ over the built-in WebSocket server. Turn it on in OBS under Tools → WebSocket Server Settings and you're connected.

  • Follow OBS: hit record in OBS and StreamWave records too. Pause and stop together.
  • Scene markers: every scene switch drops a marker, so you can find the highlights later.
  • Split tracks: mic, desktop and Discord from one OBS file become separate, editable tracks.
  • Send back to video: put the cleaned-up audio into a copy of the video, without re-encoding the picture, and with chapters from your markers.
  • Auto-reconnect: OBS restarted? StreamWave reconnects on its own and shows you the status.

🛡 Windows: the installer isn't code-signed yet. If SmartScreen appears, click More info → Run anyway.

🐧 Linux install: sudo apt install ./StreamWave-0.8.4-linux-x86_64.deb · sudo dnf install ./StreamWave-0.8.4-linux-x86_64.rpm · sudo pacman -U ./StreamWave-0.8.4-linux-x86_64.pkg.tar.zst · or chmod +x the AppImage and run it. Package installs update by installing the new package; the app tells you when there is one.

🍎 Mac, first launch: drag StreamWave into Applications. It isn't notarised by Apple yet, so the first time right-click (or Control-click) the app, choose Open, then Open again. On newer macOS (Sequoia 15+), go to System Settings → Privacy & Security and click Open Anyway. After that it opens normally. To update, download the new .dmg and replace the app in Applications.
